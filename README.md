# AI Shadow IT Risk Assessment and Policy Draft

## Context Statement

This is a self directed learning exercise, not a professional engagement. I created a fictional company called MediTech Solutions and imagined a scenario where its employees are using public generative AI tools without oversight. My goal was to practice building a risk register, drafting an acceptable use policy, and mapping controls to recognised frameworks. All data, risks, and decisions are hypothetical. This work represents my approach to structured GRC thinking, not a claim of industry experience.

## Project Contents

This folder contains four files.

| File | Description | Format |
|------|-------------|--------|
| Risk Register | Five fictional risks related to unsanctioned AI use, scored and treated | Excel (.xlsx) |
| Acceptable Use Policy | A one page draft policy for employee use of generative AI tools | PDF or Markdown |
| Control Mapping | Each proposed control mapped to ISO 27001:2022 and NIST CSF 2.0 | Excel (.xlsx) |
| Reflection Note | Honest personal reflection on what I learned and found difficult | Markdown |

## Why This Project Matters for a GRC Role

This project demonstrates the ability to think proactively about emerging risk, structure a risk register with logical scoring, draft a policy that is readable by non technical employees, and align controls with recognised frameworks. These are core activities in any junior governance, risk, and compliance position.
